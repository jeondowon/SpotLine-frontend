# SpotLine

Vision AI로 오프라인 매장의 고객 행동을 비식별 데이터로 분석하고, 매출 향상을 위한 운영 전략을 제안하는 AI 매장 분석 플랫폼.

## 기술 스택

- React + Vite
- JavaScript

## 시작하기

```bash
npm install
npm run dev
```

## 환경변수

`.env` 파일을 루트에 생성 후 필요한 변수를 설정

```
VITE_API_BASE_URL=
VITE_KAKAO_REST_API_KEY=
```

## 협업 방식 (Git Flow)

### 브랜치 전략

| 브랜치               | 역할                                           |
| -------------------- | ---------------------------------------------- |
| `main`               | 배포용 브랜치. 직접 커밋 금지                  |
| `dev`                | 개발 통합 브랜치. 모든 작업의 기반이자 PR 대상 |
| `feat/#이슈번호`     | 기능 개발 브랜치                               |
| `fix/#이슈번호`      | 버그 개선 브랜치                               |
| `refactor/#이슈번호` | 리팩터링 브랜치                                |

### 작업 흐름

**1. GitHub 이슈 생성**

작업할 기능이나 버그를 이슈로 먼저 등록한다. 이슈 번호가 브랜치명의 기준이 된다.

**2. 브랜치 생성**

`dev`를 기반으로 `feat/#이슈번호` 형식으로 브랜치를 생성한다.

```bash
git checkout dev
git pull origin dev
git checkout -b feat/#이슈번호
```

**3. 작업 및 커밋**

커밋 메시지는 변경 내용을 간결하게 한국어로 작성한다.

```bash
git add .
git commit -m "기능 설명"
```

**4. PR 생성**

작업 완료 후 `dev` 브랜치를 대상으로 PR을 생성한다.

- Base: `dev`
- Compare: `feat/#이슈번호`
- PR 제목: 커밋 메시지와 동일하게 작성

### 브랜치 명명 규칙

```
feat/#22   # 이슈 #22에 해당하는 기능 개발
fix/#18   # 이슈 #18에 해당하는 기능 개발
refactor/#54    # 이슈 #54에 해당하는 기능 개발
```
